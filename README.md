# 神州大富翁 / CHINA TYCOON

支持 2–4 人同屏轮流操作、电脑玩家和同一局域网房间的 3D 网页大富翁。

## 启动

Windows 双击 `start.bat`。首次运行会安装依赖并构建。也可手动运行 `npm install && npm run build && npm start`。本机访问 http://localhost:4173；终端会列出局域网 IP 地址。联机仅面向可信的同一局域网，不提供公网账户或加密连接。

开发时运行 `npm run dev`（前端 5173），另开终端运行 `npm start`（服务端 4173）。

## 玩法

掷两枚骰子并逐格前进。经过起点获得 ¥200；到达无主城市可购买，进入别人拥有且未抵押的城市支付租金。平房可升级为小楼、公寓、大厦；完整持有同一地区且都未抵押会触发联动，租金乘以 1.5。资金不足时变卖建筑或抵押地产，也可破产。达到轮数上限按总资产排名。

单机游戏自动保存在浏览器 localStorage。联机游戏保存在 `data/rooms.json`，此目录不会被静态服务器公开。身份令牌只保存在加入房间的浏览器中，邀请链接仅含房间号。服务器逐项验证当前玩家身份、回合阶段、地产归属和资金。

## 数据与结构

`shared/board.js` 定义棋盘；`shared/game.js` 定义纯规则；`src/` 为界面和 3D 场景；`server/index.js` 为联机服务器。城市经纬度是参考 [GeoNames 城市数据库](https://www.geonames.org/) 的近似城市中心点，供地产资料展示。棋盘是游戏布局，不是按比例地理地图。3D 建筑、棋子和 UI 插画均以项目内代码绘制，不需要外部模型或 CDN。
